# تطبيق النادل (Kotlin + Jetpack Compose)

يتصل بنظام الكاشير (Restaurant POS Desktop) عبر الواي فاي المحلي، ويرسل الطلبات للمطبخ.

## التشغيل
1. في البرنامج: أنشئ مستخدماً بدور «نادل» (صفحة المستخدمين)، ثم صفحة «تطبيق النادل» ← فعّل ← احفظ. اسمح لويندوز بالوصول عبر الشبكة الخاصة (TCP للمنفذ، وUDP/3839 للبحث التلقائي).
2. ثبّت الـAPK على الجوال (من Releases بعد الدفع إلى GitHub، أو Android Studio ← Run).
3. يجد التطبيق الكاشير تلقائياً (أو أدخل العنوان يدوياً) ← عند أول مرة طابق «بصمة الأمان» مع الشاشة واضغط «تطابق» ← اختر اسمك ← الرمز السري ← اختر طاولة ← أضف الأصناف ← «إرسال للمطبخ».
4. للتنبيهات والتطبيق مغلق: اسمح بالإشعارات وبتجاوز توفير البطارية عند الطلب (وعلى شاومي/هواوي/سامسونج فعّل «التشغيل التلقائي» وألغِ تقييد البطارية للتطبيق).

## البناء محلياً
`gradle :app:assembleDebug` (Gradle 8.9 + JDK 17 + Android SDK 34) أو افتح المجلد في Android Studio.
